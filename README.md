## Инструкция по запуску

**Требования:** Python 3

### Шаги:

1. **Установите зависимости** из `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

2. **Выполните** в корневой папке проекта:

   ```bash
   python .\manage.py runserver
   ```

3. **Откройте** сайт в браузере:

   http://127.0.0.1:8000/
